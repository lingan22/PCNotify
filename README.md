# PCNotify

轻量级 Windows 电脑状态监控与手机即时消息推送守护程序。

---

## 🌟 核心特性

- **系统事件感知**：实时捕获 Windows 开机自启、登录、锁屏与解锁事件。
- **多通道聚合推送**：支持企业微信群机器人（可免实名直达个人普通微信）、飞书大横幅卡片、钉钉、ntfy、WxPusher 及自定义 Webhook。
- **硬件实时快照**：随附当前 CPU 负荷、内存占用、显卡状态及电池续航摘要。
- **极简现代控制台**：Win11 Fluent 风格卡片界面，支持平滑缩放、系统托盘常驻与免打扰一键暂停。
- **绿色单文件**：纯独立执行文件（< 1 MB），无需安装配置，开箱即用。
